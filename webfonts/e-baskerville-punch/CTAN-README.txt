BaskervillePunch Font Package
-----------------------------

This package provides LaTeX files needed to use the Baskerville Punches font, first released in 2026. 

Baskerville Punch is an open-source font family that aims to bring Baskerville’s types back to life, based on the original punches cut between 1750 and 1775, which are preserved in Cambridge today.

Included are the "text" flavor of the opentype fonts, the corresponding type 1
fonts, and what's necessary to use them with LaTeX.
The fonts are licensed under the OFL.
