# letsum-mirror

[LETSUM(렛섬)](https://letsum.app)이 제공하는 **재배포 허용 라이선스(OFL 등) 한글 무료 폰트의 원본 미러**입니다.

- 각 릴리스 = 폰트 1종. 자산 `<id>.zip` 안에 폰트 파일(TTF/OTF), 원문 라이선스(OFL.txt), 출처(SOURCE.txt)가 들어 있습니다.
- 파일은 원 배포처(Google Fonts, GitHub 릴리스)에서 그대로 받아 묶었으며 수정하지 않았습니다. sha256은 letsum 저장소 `tools/state/archive.json`에 기록됩니다.
- 모든 폰트의 저작권은 각 저작권자에게 있습니다. OFL 폰트는 폰트 파일 단독 유료 판매가 금지됩니다. 사용 범위는 각 ZIP의 라이선스 원문을 따릅니다.
- 권리자 요청 시 즉시 내립니다: letsum.app 문의.
